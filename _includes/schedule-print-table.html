{% comment %} Print-only timetable: one table per day, one page per day, rooms as columns. Hidden on screen — the interactive grid covers that — and shown only by the @media print rules, which also hide the grid because it doesn't paginate. Rows are the intervals between every start and end time of the day, so a row boundary exists wherever anything begins or ends. Intervals in which nothing runs are skipped, which keeps the 16:00–16:05 kind of gap from printing as a sliver. An event therefore always covers whole rows, and its `rowspan` is simply the number of rows between its start and its end. Cells carry data-day / data-room so the filter state from main.js applies here as it does to the grid and the agenda list. {% endcomment %} {% comment %} Page setup lives here rather than in style.css because @page cannot be limited to one page of the site: putting it in the shared stylesheet would turn every printed page landscape. It belongs to whichever page includes the timetable, which needs the width for six room columns. The margin is 8mm on purpose. Chrome draws its own date, page title, URL and page number inside the page margin, and only when that margin is wide enough to hold them: at 9mm they appear, at 8mm they do not. Widening this brings them back. {% endcomment %} {% assign rooms = site.data.schedule.rooms %}
